# 4. Repositorio: GitHub

## ¿Qué es GitHub?

**GitHub** es una plataforma online que permite a los desarrolladores **guardar, gestionar y compartir el código fuente** de sus aplicaciones y proyectos.

Fue creado en **2008** y adquirido por **Microsoft en junio de 2018**. Actualmente es una de las plataformas más utilizadas por desarrolladores y empresas de todo el mundo.

GitHub utiliza **Git**, un sistema de control de versiones creado por **Linus Torvalds**, que permite registrar y controlar los cambios realizados en un proyecto.

---

## ¿Qué es un repositorio?

Un **repositorio** es el espacio donde se almacena un proyecto. En él podemos encontrar:

- Código fuente.
- Documentación.
- Imágenes y otros archivos.
- Diferentes versiones del proyecto.
- Historial de cambios.
- Información sobre los colaboradores.

Los repositorios pueden ser:

- **Públicos:** cualquier persona puede consultar su contenido.
- **Privados:** solamente pueden acceder las personas autorizadas.

---

## Git y GitHub

Aunque están relacionados, **Git y GitHub no son lo mismo**.

**Git** es un sistema de control de versiones que permite guardar y gestionar los cambios realizados en un proyecto.

**GitHub** es una plataforma online que utiliza Git y proporciona herramientas para almacenar proyectos, compartirlos y trabajar de forma colaborativa.

Por ejemplo, un desarrollador puede utilizar **Git** para controlar las diferentes versiones de un proyecto y después utilizar **GitHub** para subirlo a Internet y compartirlo con otros desarrolladores.

---

## ¿Para qué sirve GitHub?

GitHub ofrece diferentes herramientas que facilitan el desarrollo de software.

### Control de versiones

Permite guardar un historial de todos los cambios realizados en un proyecto. Si se produce algún problema, es posible consultar versiones anteriores y recuperar el estado anterior del código.

### Trabajo en equipo

Varios desarrolladores pueden trabajar sobre el mismo proyecto. GitHub permite organizar las contribuciones de cada persona y combinar los cambios realizados por diferentes miembros del equipo.

### Compartir proyectos

Los desarrolladores pueden publicar sus proyectos para que otras personas puedan consultarlos, utilizarlos o colaborar en ellos.

### Seguimiento de problemas

GitHub dispone de herramientas como **Issues**, que permiten informar de errores, proponer mejoras o crear tareas relacionadas con un proyecto.

### Revisiones de código

Mediante las **Pull Requests**, los desarrolladores pueden proponer cambios para que otros miembros del equipo los revisen antes de incorporarlos al código principal.

---

## GitHub como red social para desarrolladores

Además de ser una plataforma para almacenar código, GitHub también tiene características similares a una **red social profesional**.

Los usuarios pueden:

- Crear un perfil.
- Seguir a otros desarrolladores.
- Consultar proyectos.
- Colaborar en diferentes repositorios.
- Compartir sus propios proyectos.
- Participar en proyectos de código abierto.

Por este motivo, GitHub también puede utilizarse como un **portafolio profesional**, ya que permite mostrar los proyectos y conocimientos de programación de un desarrollador.

---

## GitHub y el código abierto

Una de las características más importantes de GitHub es su relación con el **software de código abierto (Open Source)**.

Un proyecto de código abierto permite que otras personas puedan consultar su código y, dependiendo de la licencia utilizada, modificarlo y distribuirlo.

Gracias a GitHub, miles de desarrolladores pueden colaborar en proyectos desde diferentes lugares del mundo sin necesidad de trabajar físicamente en el mismo sitio.

---

## Conceptos importantes de GitHub

| Concepto | Descripción |
|---|---|
| **Repositorio** | Espacio donde se almacena un proyecto y su historial. |
| **Commit** | Registro de los cambios realizados en los archivos. |
| **Branch** | Rama independiente del proyecto que permite trabajar en cambios sin modificar directamente la rama principal. |
| **Merge** | Proceso mediante el cual se combinan los cambios de diferentes ramas. |
| **Pull Request** | Solicitud para incorporar cambios de una rama a otra después de revisarlos. |
| **Issue** | Herramienta para informar de errores, proponer mejoras o gestionar tareas. |
| **Fork** | Copia de un repositorio que permite trabajar sobre él de manera independiente. |
| **Clone** | Acción de descargar un repositorio desde GitHub al ordenador. |

---

## Ventajas de utilizar GitHub

- Permite almacenar proyectos en Internet.
- Facilita el trabajo colaborativo.
- Mantiene un historial de los cambios realizados.
- Permite recuperar versiones anteriores.
- Facilita la revisión del código.
- Permite compartir proyectos con otros desarrolladores.
- Favorece el desarrollo de proyectos de código abierto.
- Puede utilizarse como portafolio profesional.
- Permite gestionar tareas, errores y mejoras de un proyecto.

---

## GitHub en la actualidad

GitHub se ha convertido en una herramienta fundamental dentro del mundo del desarrollo de software.

Su comunidad reúne a **millones de desarrolladores y organizaciones** que utilizan la plataforma para crear, compartir y mantener proyectos.

Además, GitHub ha incorporado herramientas relacionadas con la **automatización, la colaboración y la inteligencia artificial**, ampliando sus funciones más allá del simple almacenamiento de código.

En definitiva, **GitHub no es solamente un lugar donde guardar código**, sino una plataforma completa que permite desarrollar proyectos, trabajar en equipo, compartir conocimientos y colaborar con desarrolladores de todo el mundo.
