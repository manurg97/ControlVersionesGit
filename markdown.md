# Lenguaje de marcas: Markdown

## ¿Qué es Markdown?

Markdown es un **lenguaje de marcado ligero** diseñado para dar formato a un texto de forma sencilla utilizando caracteres especiales.

* **Origen:** Creado en 2004 por John Gruber como una herramienta para convertir texto plano a HTML.
* **Finalidad:** Permitir la creación de contenido legible, fácil de escribir y de mantener, sirviendo como un método de escritura ágil.
